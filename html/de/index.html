CV-Assistent / OpenAI

Wenn Sie den CV-Assistenten nutzen, werden Ihre aktuelle Frage und der begrenzte Chatverlauf an die OpenAI API gesendet, um eine Antwort zu erzeugen. Die Anwendung nutzt die Responses API mit store=false und einer pseudonymen Sicherheitskennung; die rohe Client-IP wird nicht als diese Kennung übermittelt. OpenAI gibt an, API-Daten nicht zum Training seiner Modelle zu verwenden, sofern der Kunde nicht ausdrücklich einwilligt. Standardmäßige Missbrauchsprotokolle können Prompts und Antworten bis zu 30 Tage enthalten.

Bot-Schutz / Cloudflare Turnstile

Turnstile wird verwendet, wenn Sie den Assistenten starten oder geschützte Kontaktdaten freischalten. Cloudflare verarbeitet Sicherheits- sowie Browser-/Netzwerksignale, um Menschen von automatisiertem Verkehr zu unterscheiden, und gibt an, dass Turnstile keine Formulareingaben oder Nutzerkommunikation abruft, speichert oder überträgt.

Cloudflare Web Analytics

Wenn Cloudflare Web Analytics aktiv ist, wird es nur für aggregierte Seiten- und Leistungsmessungen verwendet. Cloudflare gibt an, dass Web Analytics keine personenbezogenen Daten von Besuchern erhebt oder verwendet.

Lokale Aufbewahrung & Betriebsdaten

Der Assistent meldet dem Browser seine aktive lokale Chat-Aufbewahrung. Die datensparsame Source-Voreinstellung beträgt 0 Tage; abgeschlossene Frage-/Antworttexte werden dann lokal nicht gespeichert. Pseudonyme Zeitstempel für Rate-Limits und aggregierte Tageszähler bleiben zur Missbrauchsabwehr erhalten. Operative Telegram-Benachrichtigungen verwenden standardmäßig nur eine pseudonyme Interaktionskennung und enthalten keine Frage-/Antworttexte. Die geschützte Telefonnummer wird erst nach erfolgreicher Turnstile-Prüfung ausgegeben und ist nicht in der statischen Website eingebettet.
