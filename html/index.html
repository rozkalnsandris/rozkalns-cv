Privacy & data use

Controller: Andris Rožkalns. Public location: 44319 Dortmund, Germany. Privacy contact: andris@rozkalns.net.

CV Assistant / OpenAI

If you use the CV Assistant, your question and bounded chat history are sent to the OpenAI API to generate an answer. The application uses the Responses API with store=false and a pseudonymous safety identifier; it does not send the raw client IP as that identifier. OpenAI states that API data is not used to train its models unless the customer opts in, while default abuse-monitoring logs may contain prompts and responses for up to 30 days.

Bot protection / Cloudflare Turnstile

Turnstile is used when you enter the assistant or verify protected contact details. Cloudflare processes security and browser/network signals to distinguish people from automated traffic and states that Turnstile does not access, store or transmit form entries or user communications.

Cloudflare Web Analytics

If Cloudflare Web Analytics is active, it is used only for aggregate page and performance measurement. Cloudflare states that Web Analytics does not collect or use visitors' personal data.

Local retention & operational data

The assistant reports its active local chat-retention setting to the browser. The privacy-minimizing source default is 0 days, so completed question/answer text is not stored locally. Pseudonymous rate-limit timestamps and aggregate daily counters remain for abuse control. Operational Telegram notifications use a pseudonymous interaction identifier by default and do not include question/answer text. The protected phone number is returned only after successful Turnstile verification and is not embedded in the static site.

Legal basis & transfers

Where these operations involve personal data, the legal basis is Art. 6(1)(f) GDPR: the legitimate interests in operating a secure public portfolio, answering optional CV questions and preventing abuse. OpenAI's DPA states that EEA/Swiss data is handled under OpenAI Ireland Ltd. and onward transfers use SCCs or an adequacy decision. No special OpenAI zero-retention or EU-residency account feature is claimed.

Your rights

Where GDPR applies, you may request access, correction, deletion, restriction or object to processing, and you may lodge a complaint with a competent data-protection authority. Use andris@rozkalns.net for privacy requests.
