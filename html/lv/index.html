CV asistents / OpenAI

Ja izmantojat CV asistentu, jūsu aktuālais jautājums un ierobežotā tērzēšanas vēsture tiek nosūtīta OpenAI API, lai sagatavotu atbildi. Lietotne izmanto Responses API ar store=false un pseidonīmu drošības identifikatoru; neapstrādāta klienta IP adrese netiek sūtīta kā šis identifikators. OpenAI norāda, ka API dati netiek izmantoti modeļu apmācībai, ja vien klients tam nav īpaši piekritis; standarta ļaunprātīgas izmantošanas uzraudzības žurnāli var saturēt uzvednes un atbildes līdz 30 dienām.

Aizsardzība pret botiem / Cloudflare Turnstile

Turnstile tiek izmantots, kad atverat asistentu vai pārbaudāt aizsargātos kontaktus. Cloudflare apstrādā drošības un pārlūka/tīkla signālus, lai atšķirtu cilvēkus no automatizētas datplūsmas, un norāda, ka Turnstile nepiekļūst veidlapu ievadei vai lietotāju saziņai, to neglabā un nepārsūta.

Cloudflare Web Analytics

Cloudflare Web Analytics ir ieslēgts apkopotai lapu un veiktspējas mērīšanai. Cloudflare norāda, ka Web Analytics nevāc un neizmanto apmeklētāju personas datus.

Lokālā glabāšana un darbības dati

Asistents pārlūkam paziņo aktīvo lokālās tērzēšanas glabāšanas iestatījumu. Privātumu saudzējošā source noklusējuma vērtība ir 0 dienas, tādēļ pabeigtu jautājumu/atbilžu teksts lokāli netiek glabāts. Pseidonimizēti ātruma ierobežojumu laika zīmogi un apkopoti dienas skaitītāji paliek aizsardzībai pret ļaunprātīgu izmantošanu. Operatīvie Telegram paziņojumi pēc noklusējuma izmanto tikai pseidonīmu mijiedarbības identifikatoru un neietver jautājumu/atbilžu tekstu. Aizsargātais tālruņa numurs tiek atdots tikai pēc sekmīgas Turnstile pārbaudes un nav iegults statiskajā vietnē.

Juridiskais pamats un datu pārsūtīšana

Ciktāl šajās darbībās tiek apstrādāti personas dati, juridiskais pamats ir VDAR 6. panta 1. punkta f) apakšpunkts: leģitīmās intereses droši uzturēt publisku portfolio, pēc izvēles atbildēt uz CV jautājumiem un novērst ļaunprātīgu izmantošanu. OpenAI DPA paredz, ka EEZ/Šveices dati tiek apstrādāti OpenAI Ireland Ltd. ietvaros un tālākai pārsūtīšanai izmanto SCC vai lēmumu par aizsardzības līmeņa pietiekamību. Netiek apgalvots, ka OpenAI kontam ir īpaša nulles glabāšanas vai ES datu rezidences funkcija.
